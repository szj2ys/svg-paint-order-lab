AN OPEN, OFFLINE ILLUSTRATION EXERCISE

Two colors. Three passes.

Changing the order of same-colored SVG shapes can remove a detail. Inspect the four files below, then compare their pixels in your browser. No account, upload, server, or library is needed.

Test the visual consequence

Render all examples at 300 × 180 pixels using this browser's SVG renderer. Count pixels whose RGBA values differ from the original; fully transparent pixels are normalized to zero RGB before comparison.

Try it yourself

  1. Download the original and the two broken examples.
  2. Open their markup in a text editor. Only the shape order changes.
  3. Open them in a browser or vector editor and find the missing detail.
  4. Keep the original canvas and shape sequence when exporting separate files. Reassemble and compare before trusting an export.

This fixture illustrates a specific overlap. It does not prove that every repeated color always needs another pass. Non-overlapping shapes may be combined safely after checking geometry. This is not a general SVG parser, production separator, cutter test or registration tool.

The W3C rendering model explains document painting order. An optional practical application is Pic2SVG's local solid-fill splitter. This lab was prepared on behalf of Pic2SVG; using that service is not required to run any exercise here.
